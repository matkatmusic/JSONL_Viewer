Partial reconstruction — pick a treatment

All three assume the engine emits per-revision recovered / unrecoverable state with a reason. Palette + classes borrowed from the live webapp styles.css.

Option A — Banner + inline gap markers

Session banner with counts; unrecoverable spans appear as dashed gap rows in the timeline, and missing revisions render as dashed grayed cards in the revision stepper.
