## Task 134 — timeline toggle: one row per JSONL record

User-confirmed design: real in-timeline rows derived from `document.lineVerdicts`,
NOT a link to the raw-lines view. The toggle is opt-in, default off, and re-renders
the timeline through `renderRoute()` (the app-consent precedent).

Facts the design rests on (verified during planning):
- The project timeline document is built from ALL project JSONLs' records flattened
  chronologically (`loadProjectRecords` in `src/viewer_api_records.ts`), and
  `lineVerdicts` is built over that same records array — so it already covers every
  line of every file. `LineVerdict` today = `{ line, uuid, type, verdict, isGenuinePrompt }`
  (`src/reconstruction_json.ts:101`) — no timestamp/sessionId, which nodes need for
  chronological sort and lane color. `TranscriptRecord` (EnvelopeBase,
  `src/structures/envelope.ts`) carries optional hydrated `uuid: Uuid`,
  `sessionId: Uuid`, `timestamp: Date`.
- Existing turn rows and tool-call rows already represent their JSONL lines, so line
  nodes are emitted only for verdicts whose `uuid` is NOT already a message or
  tool-call uuid (otherwise those lines would render twice).
- `checkNodeMatchesFilterMode` needs NO change: non-`all` modes match only their
  specific kinds, so line rows show under "All" (and under search via `node.text`),
  exactly right.
- `computeRowSummaryText`'s fallthrough branch reads `node.text` — giving `LineNode`
  a real `text: string` makes the summary render with zero changes there.
  `computeRoleClass` falls through to `"role-end"` (muted) — acceptable dim styling
  for raw lines; no CSS change.
- `resolveLineLabels` / `appendJsonRecordButton` / `openNodeInspector` all key on
  `node.uuid` + `node.sessionId` and already tolerate undefined uuids (synthetic
  turns) — line nodes inherit "L:n (of N)" labels and a working `{ }` button for
  free.

```ts
// Task 134: the "show every JSONL line" toggle — one timeline row per transcript record that
// is not already a turn or tool-call row. Model + storage accessors live here (their one
// canonical home); timeline-types.ts sits at the 250-line cap and only unions the type in.

import type { WireTimelineDocument } from "./timeline-types.ts";

export const LINE_NODE_KIND = "jsonl-line";
const ALL_LINES_STORAGE_KEY = "timeline:allLines";
const ALL_LINES_ON_VALUE = "1";

// The engine's per-line verdict on the wire (LineVerdict in src/reconstruction_json.ts;
// dates/uuids arrive as plain strings).
export type WireLineVerdict = {
    line: number;
    uuid?: string;
    type: string;
    verdict: string;
    timestamp?: string;
    sessionId?: string;
};

// One raw-transcript-line row. Mirrors the union convention in timeline-types.ts: every
// field another node kind carries is declared `?: undefined` so union property access
// stays legal.
export type LineNode = {
    kind: typeof LINE_NODE_KIND;
    when: string;
    sessionId: string | undefined;
    uuid?: string;
    text: string;
    stepNumber?: undefined;
    isSystem?: undefined;
    isOrphaned?: undefined;
    isGitBaseline?: undefined;
    snapshots?: undefined;
    gitOperations?: undefined;
    fileChanges?: undefined;
    detail?: undefined;
    resultHash?: undefined;
    isError?: undefined;
    summary?: undefined;
    toolName?: undefined;
    toolUseId?: undefined;
    scriptRun?: undefined;
};

// A verdict line gets its own row unless a turn or tool-call row already shows that record.
function checkLineNeedsOwnRow(verdict: WireLineVerdict, representedUuids: Set<string>): boolean {
    if (verdict.uuid === undefined) {
        return true;
    }
    return !representedUuids.has(verdict.uuid);
}

// One node per not-yet-represented transcript line. Timestamp-less records (e.g. summary
// lines) sort to the top via when="" — where they physically sit in the file.
export function deriveLineNodes(document: WireTimelineDocument): LineNode[] {
    const representedUuids = new Set<string>([
        ...document.messages.map((message) => message.uuid),
        ...(document.toolCalls ?? []).map((call) => call.uuid),
    ]);
    return (document.lineVerdicts ?? [])
        .filter((verdict) => checkLineNeedsOwnRow(verdict, representedUuids))
        .map((verdict) => ({
            kind: LINE_NODE_KIND,
            when: verdict.timestamp ?? "",
            sessionId: verdict.sessionId,
            uuid: verdict.uuid,
            text: `${verdict.type} · ${verdict.verdict}`,
        }));
}

export function checkAllLinesIsOn(): boolean {
    return sessionStorage.getItem(ALL_LINES_STORAGE_KEY) === ALL_LINES_ON_VALUE;
}

export function toggleAllLinesSetting(): void {
    if (checkAllLinesIsOn()) {
        sessionStorage.removeItem(ALL_LINES_STORAGE_KEY);
        return;
    }
    sessionStorage.setItem(ALL_LINES_STORAGE_KEY, ALL_LINES_ON_VALUE);
}
```
