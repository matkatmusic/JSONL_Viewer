## Step 1 — Task 197: `jfred/src/layered_instants.ts` (+ `jfred/tests/layered_instants.test.ts`)

The S1 axis-placement helper. `Instant` is `layered_types.ts`'s `export type
Instant = Date` — import it from there.

Exports:

1. `widenCommitterSecondsToInstant(committerEpochSeconds: number): Instant`
   — `new Date(committerEpochSeconds * 1000)`. Git committer time arrives in
   whole seconds; the shared axis is UTC ms.

2. `AxisPlacement` interface — the sortable view of a timeline node:
   ```ts
   export interface AxisPlacement {
       instant: Instant;
       // True when the instant was widened from git committer seconds — its true
       // moment is anywhere inside that second, so same-second comparisons against
       // ms-precision JSONL instants must fall back to content order (hpp Q7/Q9).
       widenedFromSeconds: boolean;
       // Full content when the node carries it (beacon/end-state); undefined otherwise.
       content: string | undefined;
   }
   ```

3. `compareAxisPlacements(a: AxisPlacement, b: AxisPlacement): number` — the one
   comparator every layered timeline sort uses. Rules, in order:
   - Compute `secondOf = Math.floor(ms / 1000)` for both. The content-order
     tiebreak applies ONLY when both fall in the same second AND exactly one side
     is `widenedFromSeconds` (a widened instant means "somewhere in this second",
     so the raw ms comparison is meaningless against an ms-precision peer).
   - Tiebreak, both contents known:
     - contents EQUAL → the widened (git) node sorts AFTER the ms node: the
       commit blob snapshotted the state the JSONL row produced (corroboration).
     - contents DIFFER → the widened node sorts BEFORE the ms node: had the
       commit happened after the JSONL change, its blob would hold that content.
     // ponytail: single-change-per-second rule; refine with multi-change chains if a real corpus contradicts it.
   - Tiebreak with either content undefined → fall back to plain ms comparison.
   - No tiebreak condition → `a.instant.getTime() - b.instant.getTime()`
     (stable sort preserves source order for exact ms ties — JSONL line order IS
     content order within a session).

Tests (write FIRST, each with plain-English step comments, `test_` names):
- `test_widenCommitterSecondsToInstant_multiplies_by_1000` — 1_700_000_000 s →
  Date at 1_700_000_000_000 ms.
- `test_same_second_equal_content_places_commit_after_jsonl` — widened placement
  at 10:00:00 with content "A\n", ms placement 10:00:00.400 content "A\n" →
  comparator orders jsonl first, commit second (both argument orders).
- `test_same_second_differing_content_places_commit_before_jsonl` — same instants,
  commit content "OLD\n" vs jsonl "NEW\n" → commit first.
- `test_same_second_unknown_content_falls_back_to_ms_order` — commit content
  undefined → 10:00:00.000 (widened) sorts before 10:00:00.400.
- `test_different_seconds_order_by_ms` — no tiebreak across seconds.

## Step 2 — Task 196: `jfred/src/layered_load.ts` (+ `jfred/tests/layered_load.test.ts`)

S1 loader: discovery + per-file entities from JSONL rows. Layer-1 node semantics
(anchor selection, end state, gap nodes) are S2/tasks 198-199 — NOT here. Here a
row with full content becomes a `BeaconNode`, any other file-touching row becomes

Reuse (do not reimplement): `loadTranscript` (`src/parse/loadTranscript.ts`),
`extractFileEvents` (`src/reconstruction_extract.ts`), `getContentBlocks` +
`BlockType` for tool_use line mapping, `getRecordSource`
(`src/parse/loadTranscript.ts`), `findFirstRecordCwd`
(`src/reconstruction_base_commit.ts`), `resolveFileHistoryRoot`
(`src/reconstruction_sidecar_reader.ts`), `compareAxisPlacements` +
`widenCommitterSecondsToInstant` from Step 1, types from `layered_types.ts`,
`Path` from `structures/domain.ts`, `EventKind`/`LayeredNodeKind` from
`structures/vocabulary.ts` (enum-member comparisons only).

Exports:

1. `LayeredSourceOverrides` — `{ repoPath?: Path; jsonlPaths?: Path[]; snapshotPaths?: Path[] }`
   (names per spec S1).

2. `discoverJsonlPaths(projectFolder: Path, override: Path[] | undefined): Path[]`
   — override wins verbatim; otherwise `readdirSync(projectFolder)` top-level
   entries ending `.jsonl`, name-sorted, resolved against the folder.

3. `resolveEvidenceRoots(records: TranscriptRecord[], overrides: LayeredSourceOverrides): { repoPath: Path | undefined; snapshotPaths: Path[] }`
   — repoPath: `overrides.repoPath ?? findFirstRecordCwd(records)`;
   snapshotPaths: `overrides.snapshotPaths ??` (`resolveFileHistoryRoot(records)`
   wrapped in a one-element array; empty array when it throws — wrap in
   try/catch, the fixture sessions have no sidecar). Consumed by layers 2-3
   (tasks 200-202); S1 delivers the explicit-paths-win resolution itself.

4. `loadLayeredProject(projectFolder: Path, overrides: LayeredSourceOverrides): ReconstructionGraph`
   — per session file from `discoverJsonlPaths`:
   - `loadTranscript(path)` (strict mode) → session records.
   - Build the JsonlRef index for the session: walk records; for each
     `getContentBlocks(record)` block with `type === BlockType.toolUse`, map
     `block.id.toString()` → `{ sessionFile, line: getRecordSource(record).lineNumber }`.
     Extract this walk as `indexJsonlRefsByChangeId(records, sessionFile)` (module-private).
   - `extractFileEvents(sessionRecords)` → for each event with a mapped changeId:
     `EventKind.write` → `BeaconNode { kind: LayeredNodeKind.beacon, instant: event.timestamp, content: event.content, evidence }`;
     every other kind → `PreAnchorStubNode { kind: LayeredNodeKind.preAnchorStub, instant, evidence }`.
     Events with no mapped changeId are skipped.
     // ponytail: S1 places rows on the axis; S2 (tasks 198/199) owns real layer-1 node semantics.
   - Group nodes by `event.target.toString()` then session file; sort each
     timeline's nodes via `compareAxisPlacements` (`widenedFromSeconds: false`,
     `content` = beacon content or undefined).
   - Return `{ entities, renames: [], copies: [], scriptLinks: [] }` — typed
     edges are S6/task 203. Entities: one `ReconstructionEntity` per distinct
     absolute path, `sessionTimelines` in session-file name order.
   - Call `resolveEvidenceRoots` on the merged records so override validation
     runs on every load (result feeds layers 2-3; ignore the value for now).
