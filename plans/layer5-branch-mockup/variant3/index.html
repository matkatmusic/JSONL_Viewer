Variant 3 — inline badge (no extra lane)

A new idea, not a coined term: instead of a dimmed lane column (variant 1) or a forked track (variant 2), the abandoned branch collapses into a small badge next to the trunk node showing how many nodes it had, plus a compact row of mini dots. The bubble does not widen for the abandoned branch — only unrelated concurrent sessions (like ww455.jsonl below) still add a full lane. This fell out of comparing variants 1 and 2 side by side (task 346, task 5); it deliberately contrasts with the settled "bubble widens" rule those two variants exercise.
